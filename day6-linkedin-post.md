Day 6 of #10DaysOfVoiceAgents is live.

I built an outbound voice agent that can place a practice call, open with a clear introduction, and give an opt-out path right away.

This one uses Murf Falcon for the voice layer, so the call sounds fast and natural while the agent handles the actual conversation flow.

What I built today:

- outbound call initiation
- a spoken opening that says who is calling, why, and how to stop future calls
- a trial-friendly Twilio path for reaching a verified number
- a fallback path for SIP-style testing

Proud to be building with Murf AI as part of the 10 Days of Voice Agents challenge.
